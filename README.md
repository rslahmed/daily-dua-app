## What is Daily Dua?

Daily Dua helps you build a steady habit of remembering Allah. It brings the duas and azkar for your morning, evening and bedtime together in one simple place, so you can read them every day in Bangla, even without an internet connection.

## What's inside

Every dua includes:

- 📖 **Arabic text** in a clear, easy-to-read font
- 🗣️ **Bangla pronunciation** if you're still learning to read Arabic
- 💬 **Bangla meaning** so you understand what you're reciting
- ✨ **Benefits** of the dua, where available
- 📚 **Source references**

## Features

- 🌅 **Organized by time of day:** morning, evening and bedtime
- ✅ **Daily progress:** mark duas as read, with a fresh start each day
- 🔍 **Search:** quickly find the dua you're looking for
- 🔠 **Your reading style:** adjust the Arabic text size and choose which details to show
- 📴 **Works offline:** the app keeps working without internet
- 🔄 **Stays up to date:** new and corrected duas download automatically when you're online

## Install on Android

1. [Download the latest APK](https://github.com/rslahmed/daily-dua-app/releases/latest/download/daily-dua.apk).
2. Open the downloaded file.
3. If Android asks, allow installs from your browser or file manager.
4. Tap **Install**.

Android may warn you because the app isn't from the Play Store. This is normal for apps installed directly.

To update, download and install the newest version in the same way. Your duas also update on their own without reinstalling.
